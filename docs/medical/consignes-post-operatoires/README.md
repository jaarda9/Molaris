# Consignes post-opératoires — fiches patients (FR + AR)

> **Statut : BROUILLON — à faire valider par un médecin dentiste référent avant usage.**

| Fichier | Objet |
|---|---|
| `extraction.md` | Après une extraction dentaire (y compris dent de sagesse) |
| `chirurgie-implantaire.md` | Après la pose d'implant(s), avec cases greffe osseuse / sinus |
| `traitement-endodontique.md` | Après un traitement de canal (séance intermédiaire ou finale) |
| `detartrage-surfacage.md` | Après un détartrage ou un surfaçage radiculaire |
| `anesthesie-locale.md` | Après toute anesthésie locale (à remettre aussi aux parents d'enfants) |

## Règles d'utilisation

1. **Aucune dose ni aucun nom de médicament** dans les fiches : elles renvoient toujours à
   l'**ordonnance** (module Ordonnances), seule source pour les médicaments.
2. Les valeurs entre crochets `[…]` (durées, dates, tailles de brossettes) sont des **paramètres** que
   le praticien règle ; les valeurs proposées sont des valeurs usuelles ⚠️ À VÉRIFIER (praticien
   référent).
3. Imprimer la version arabe en droite-à-gauche : `Molaris.print.document({ dir: 'rtl', lang: 'ar' })`.
   Remettre la version choisie par le patient (ou les deux), en plus de l'explication orale.
4. Numéro d'urgence : la fiche indique le **SAMU (190)** ; ⚠️ À VÉRIFIER : confirmer le numéro et
   permettre au cabinet d'ajouter son propre numéro d'urgence dans les paramètres.
5. Les fiches consentement (`../../legal/consentements/`) mentionnent la remise de ces consignes :
   cocher la case correspondante dans le consentement.
